Install

01
Download the latest loadix-*.zip from GitHub Releases
02
Open chrome://extensions/ and enable Developer mode
03
Drag the zip into the page — or click Load unpacked and select the unzipped folder

Build from source

01
$ git clone git@github.com:hexiangtao/loadix.git
02
$ npm install
03
$ npm run build
04
chrome://extensions/ → enable Developer mode
05
Load unpacked → select .output/chrome-mv3

Loadix · Use only against systems you own or are authorized to test.
