在浏览器里锻造负载，压测你的 API

LoadForge 是一款 Chrome 浏览器扩展，面向开发者的轻量 HTTP API 负载与压力测试工作台。无需安装后端集群，点击图标即可开始。

安装扩展 查看源码
Manifest V3 WXT + React + TypeScript 中英双语 开源 MIT

核心能力

六种 HTTP 方法

GET / POST / PUT / PATCH / DELETE / HEAD，自定义请求头、超时与 JSON / form / text 请求体。

负载模型

并发虚拟用户、目标 RPS、持续时间与升压（ramp-up）策略，内置 Smoke / Normal / Stress / Spike 预设。

断言规则

HTTP 状态码、最大延迟、响应体包含文本三类断言，精准定义「成功」标准。

实时指标

请求数 / 成功 / 错误 / RPS / 平均 / P95 / P99 / 成功率，配合吞吐与延迟图表。

变量插值

在 URL、请求头、请求体中使用 {{variable}}，复用配置、灵活构造请求。

历史与报告

自动保存最近测试记录，一键恢复配置，导出 JSON 报告。

安装

  1. 克隆仓库 git clone git@github.com:hexiangtao/loadforge.git
  2. 安装依赖 npm install
  3. 构建 npm run build
  4. 打开 chrome://extensions/，开启「开发者模式」
  5. 点击「加载已解压的扩展程序」，选择 .output/chrome-mv3

快速开始

开发模式

npm run dev

启动带热更新的 dev server，加载一次扩展后即可实时调试。

打包发布

npm run zip

构建并生成可上传 Chrome Web Store 的 zip 包。

⚒️ LoadForge — 仅用于你拥有或明确授权测试的系统。基于浏览器的负载生成不能替代分布式压测基础设施。
